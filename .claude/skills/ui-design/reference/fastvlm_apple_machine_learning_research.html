FastVLM: Efficient Vision Encoding for Vision Language Models

Vision Language Models (VLMs) merge visual perception with natural language understanding. By projecting visual tokens from a pretrained image encoder directly into a Large Language Model (LLM), VLMs leverage rich visual representations alongside deep reasoning capabilities. This enables powerful applications ranging from accessibility aids, user interface automation, robotics, and real-time scene understanding.

A primary bottleneck in modern VLMs is the trade-off between image resolution and inference latency. While higher resolutions significantly improve accuracy on detailed visual tasks, they dramatically increase computational cost and token length, hindering real-time on-device deployment.

In a research paper presented at CVPR 2025, Apple ML researchers introduced FastVLM—a novel VLM architecture designed to overcome this trade-off. By utilizing a hybrid vision encoder (FastViTHD) optimized specifically for high-resolution images, FastVLM achieves state-of-the-art efficiency and speed without compromising task accuracy.

Image Resolution and the Accuracy-Latency Tradeoff

VLM performance relies heavily on input resolution. High-resolution input is required to parse complex textual elements, traffic signs, or fine details in user interfaces. As shown in Figure 1, when asked about a distant street sign, a standard low-resolution model fails to read the text correctly, whereas a high-resolution model easily identifies the exact sign.

Hybrid Vision Encoders Deliver the Best Accuracy-Latency Tradeoff

To determine the most efficient vision backbone, we benchmarked multiple architectural paradigms under identical training setups. Comparing standard Vision Transformers (ViT-L/14, SigLIP-SO400), pure ConvNets (ConvNeXT-L), and hybrid architectures (FastViT), hybrid designs delivered optimal accuracy per millisecond. FastViT achieved an 8x reduction in model parameter footprint and ran up to 20x faster than standard ViT encoders.

FastViTHD: An Optimal Vision Encoder for VLMs

Although FastViT is efficient, directly scaling its layer capacity for high resolutions introduces compute redundancies. To overcome this, we designed FastViTHD, a high-resolution vision encoder that incorporates an additional hierarchical downsampling stage along with multi-scale feature pooling. This structural improvement generates 4x fewer tokens than FastViT and 16x fewer tokens than standard ViT-L/14 at 336x336 resolution.

FastVLM Outperforms Token Pruning and Merging Methods

Prior acceleration techniques rely on heuristic token pruning or merging during inference. However, these post-hoc techniques often discard crucial spatial context. Because FastViTHD produces inherently compact tokens directly during visual encoding, FastVLM achieves superior task accuracy across token budgets without requiring complex pruning algorithms.

Conclusion

FastVLM redefines the trade-off between image resolution and inference latency in Vision Language Models. By introducing the FastViTHD hybrid backbone, FastVLM delivers high-quality visual token representations with dramatically reduced latency. This simple, effective design eliminates the need for complex post-hoc token pruning or dynamic tiling, opening up new possibilities for real-time, privacy-preserving AI applications on personal devices.
