Apple debuts M5 Pro and M5 Max to supercharge the most demanding pro workflows

Built using the new Apple-designed Fusion Architecture, M5 Pro and M5 Max feature an advanced CPU, a next-generation GPU with Neural Accelerators, and higher unified memory bandwidth for a massive increase in AI compute

M5 Pro and M5 Max are built using the new Apple-designed Fusion Architecture that connects two dies with advanced IP blocks into a single SoC, delivering significant performance increases that push the limits of what's possible with the new MacBook Pro.

CUPERTINO, CALIFORNIA — Apple introduced M5 Pro and M5 Max, advanced system-on-chip architectures powering the new MacBook Pro. Built on an innovative Fusion Architecture, these processors connect dual dies into a single high-performance system featuring an 18-core CPU, scalable next-generation GPU with dedicated Neural Accelerators, unified memory controller, Media Engine, and Thunderbolt 5 support. With 6 super cores delivering world-class single-threaded speed alongside 12 new power-efficient performance cores, multithreaded workloads run up to 30% faster than previous generations. Hardware-accelerated ray tracing gains up to 35% higher rendering performance, while AI compute capacity increases more than 4x.

"M5 Pro and M5 Max represent a breakthrough for Apple silicon, scaling core compute capabilities through our Fusion Architecture while maintaining our relentless focus on energy efficiency and unified memory performance," said Johny Srouji, Apple's senior vice president of Hardware Technologies.

The advanced CPU cores, next-generation GPU, and higher unified memory bandwidth on M5 Pro and M5 Max enable users to bring their biggest ideas to life with great speed and efficiency. This means users can experience accelerated code compilation and on-device agentic coding in apps like Xcode.

All-New Fusion Architecture

M5 Pro and M5 Max introduce the Apple-designed Fusion Architecture, a state-of-the-art design that connects two dies into a single SoC. This brings together two third-generation 3-nanometer dies with high bandwidth and low latency using advanced packaging.

Apple's Fastest, Most Advanced CPU Cores

M5 Pro and M5 Max feature a new 18-core CPU with 6 super cores and 12 all-new performance cores. The super cores deliver industry-leading single-threaded execution speed via expanded front-end instruction decoding, an upgraded cache hierarchy, and predictive branch routing.

Alongside these super cores, 12 newly engineered performance cores handle complex multithreaded compute tasks with exceptional thermal efficiency. Combined, they yield up to 2.5x higher multithreaded performance compared to original M1 Pro and M1 Max baselines.

M5 Pro: Designed to Handle Demanding Workflows

Targeted at data analysts, financial modelers, audio engineers, and software architects, M5 Pro pairs its 18-core CPU with an up-to-20-core GPU, supported by 307 GB/s unified memory bandwidth and up to 64GB memory capacity.

M5 Pro features upgraded shader cores with second-generation dynamic caching and hardware-accelerated mesh shading, yielding up to 20% faster overall graphics performance. With Apple's third-generation ray-tracing hardware, professional rendering applications see frame rates scale up to 35% faster.

M5 Max: Unmatched Capabilities

Engineered for 3D visual effects artists, game engine developers, and machine learning researchers, M5 Max doubles GPU capacity with up to 40 cores and provides an incredible 614 GB/s unified memory bandwidth.

Advanced Technologies Across M5 Pro and M5 Max

M5 Pro and M5 Max feature a number of additional advanced technologies right on the chip, including:

  • A faster 16-core Neural Engine with a higher bandwidth connection to memory to accelerate on-device AI features and Apple Intelligence.
  • Apple's latest Media Engine with support for hardware-accelerated H.264, HEVC, AV1 decode, and ProRes encode/decode engines.
  • Support for Memory Integrity Enforcement — an industry-first, always-on memory safety protection that does not compromise device performance.
  • Thunderbolt 5 ports, each supported by its own custom-designed controller directly on the chip — making this the industry's most capable implementation of Thunderbolt 5.

Apple Silicon and the Environment

Apple 2030 is the company's ambitious plan to be carbon neutral across its entire footprint by the end of this decade by reducing product emissions from materials, electricity, and transportation. The power-efficient performance of M5 Pro and M5 Max helps MacBook Pro meet Apple's high standards for energy efficiency, and reduces the total amount of energy consumed over the product's lifetime.
