### 2. Dark/light mode toggle
Implemented a client-side toggle between Catppuccin Latte (light) and Catppuccin Mocha (dark) — both CSS files already existed as `assets/css/main.css` and `assets/css/dark.css`.

**Approach — dual-stylesheet + localStorage:**
- `_includes/head/custom.html` (new): links `dark.css` as a `disabled` stylesheet, then an inline `<script>` enables it immediately if `localStorage.theme === 'dark'` (prevents FOUC).
- `_includes/masthead.html` (new): copy of the gem's masthead with a moon/sun `<button id="theme-toggle">` added before the hamburger, plus an inline script that wires the click handler (toggles `disabled` on the dark stylesheet, swaps icon class, writes to `localStorage`).

### 4. Removed post footer blocks
Three sections at the bottom of every post were removed via empty local overrides (which take precedence over gem includes):

| File created | What it removes |
|---|---|
| `_includes/social-share.html` | "SHARE ON" social share buttons |
| `_includes/post_pagination.html` | Previous / Next navigation |

Note: `share: false` and `related: false` are already set in `_config.yml` defaults, but the empty overrides guarantee suppression regardless of any per-post front matter.
